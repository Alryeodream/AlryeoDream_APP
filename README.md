# AlryeoDream APP

맞춤형 청년 정책 알림 서비스 **'알려드림(AlryeoDream)'**의 크로스 플랫폼 모바일 애플리케이션입니다.
완벽한 소셜 로그인 연동(카카오, 네이버, 구글, 게스트)과 Firebase를 활용한 서버리스 아키텍처로 구성되어 있습니다.

## Tech Stack
- **UI Framework**: Flutter (Dart)
- **State Management**: Provider
- **Authentication**: Firebase Auth (with Kakao/Naver/Google Custom Token Integration)
- **Database**: Cloud Firestore
- **Local Storage**: Flutter Secure Storage, Shared Preferences

## Getting Started
1. `flutter pub get`
2. `flutter run` 을 통해 디버그 모드로 실행합니다.
